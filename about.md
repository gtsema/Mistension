# Mistension — Расширение для тестирования МИС

## 1. Описание и назначение проекта
**Mistension** (сокращение от *МИС + Extension*) — это браузерное расширение для Google Chrome (Manifest V3), разработанное специально для QA-инженеров и тестировщиков медицинских информационных систем (МИС). 

Основная цель проекта — автоматизировать и ускорить процесс ручного ввода валидных тестовых данных при заполнении сложных медицинских форм (карточки пациентов, заказы, адреса, документы, контакты и др.).

---

## 2. Архитектура и стек технологий
* **Платформа:** Google Chrome Extensions (Manifest V3).
* **Языки и технологии:** Vanilla JavaScript (ES6+ модули), HTML5, CSS3.
* **UI-библиотека:** Bootstrap 5 (для страницы настроек).
* **Хранилище данных:** `chrome.storage.local`.
* **Основные компоненты:**
  * `manifest.json` — конфигурация расширения (права `storage`, `scripting`, `activeTab`, `commands`, правила хостов `https://*.medzoom.ru/*`).
  * `js/background.js` — Service Worker для инициализации хранилища и обработки глобальных горячих клавиш (`commands`).
  * `js/content_autofill.js` — Content Script, отвечающий за интерактивный режим автозаполнения на странице (отслеживание кликов, сопоставление по XPath, запуск конфетти-анимации).
  * `js/randomStringUtils.js` — утилита генерации псевдослучайных строк и специализированных данных (СНИЛС, даты, регулярные шаблоны).
  * `js/utils.js` — слой работы с хранилищем, импортом и экспортом пресетов локаторов.
  * `js/autofill.js` + `html/options.html`, `html/autofill.html` — интерфейс управления базой локаторов.

## 3. Функциональность проекта

### 3.1. Интерактивный режим автозаполнения («Волшебная палочка»)
* Включение/выключение режима по горячим клавишам (`Ctrl+Shift+F` / `Command+Shift+F`).
* При активации курсор мыши заменяется на иконку волшебной палочки (`img/cursor.png`).
* При клике на поле ввода (input) расширение находит соответствующий XPath из базы локаторов, генерирует значение по заданному шаблону и вставляет его в поле.
* Инициируется событие `input` для оповещения скриптов страницы.
* Запускается визуальный эффект конфетти в месте клика.
* Поддерживается базовый выбор опций из выпадающих списков (`[role=listbox]`).

### 3.2. Генератор тестовых данных (`RandomStringUtils`)
Расширение поддерживает как статические строки, так и динамические шаблоны:
* `%snils` — генерация валидного номера СНИЛС по официальному алгоритму с расчётом контрольной суммы (формат `XXX-XXX-XXX YY`).
* `%date` — генерация случайной даты в формате `DD.MM.YYYY` (1990–2020 гг.).
* Параметрические шаблоны:
  * `%d[N]` — последовательность из `N` цифр (например, `%d4` для серии паспорта, `%d6` для номера).
  * `%s[N]` — последовательность из `N` латинских букв.
  * `%m[N]` — последовательность из `N` буквенно-цифровых символов (mixed).
* Ограничение длины генерируемой строки (до 128 символов).

### 3.3. Управление локаторами и пресетами
* **UI настроек:** Вкладка в браузере с аккордеоном всех сохранённых элементов (название, XPath, шаблон значения).
* **Валидация:** Проверка синтаксической корректности выражений XPath через `XPathEvaluator` и длины полей перед сохранением.
* **Импорт / Экспорт:** 
  * Автоматический импорт базового набора из `mistension_locators.json` при установке расширения.
  * Ручной экспорт в JSON и импорт из файла через `showOpenFilePicker`.

## 4. Сильные стороны (Преимущества)

1. **Актуальный стандарт Manifest V3:** Проект использует современный API расширений Chrome и ES-модули.
2. **Значительная экономия времени QA:** Позволяет быстро генерировать валидные и уникальные данные (особенно СНИЛС, даты, телефоны) без необходимости открывать сторонние генераторы.
3. **Наглядная визуальная обратная связь:** Смена курсора и конфетти-анимация делают работу интерактивной и интуитивно понятной.
4. **Портативность базы локаторов:** Возможность легко экспортировать и импортировать JSON-файлы с локаторами для шаринга настроек между членами команды.
5. **Валидация XPath в UI:** Предотвращает поломку расширения из-за некорректно введённых XPath-селекторов.
6. **Автономность:** Не требует внешних серверов или платных API для генерации данных.

## 5. Слабые стороны и технические ограничения

1. **Жёсткая привязка к домену в манифесте:**
   * В `manifest.json` жёстко задан `matches: ["https://*.medzoom.ru/*"]`. Расширение нельзя использовать на локальных стендах (`localhost`), других тестовых доменах или альтернативных МИС без ручной правки манифеста.
2. **Потеря данных при обновлении расширения:**
   * В `background.js` при каждом `chrome.runtime.onInstalled` вызывается `chrome.storage.local.clear()`, что удаляет все пользовательские локаторы при перезагрузке расширения в режиме разработчика.
3. **Ограничения генератора данных:**
   * Шаблон `%s` генерирует только латиницу (`A-Za-z`), тогда как для русскоязычных МИС критически важна генерация кириллических данных (ФИО, адреса, диагнозы).
   * Диапазон дат ограничен 1990–2020 годами и максимум 28 днями в месяце (исключены дни 29–31).
   * Отсутствуют генераторы полисов ОМС (16 цифр), ИНН (10/12 цифр), ОГРН, паспортов РФ (с кодами подразделений), реалистичных адресов.
4. **Несовместимость с реактивными фреймворками (React / Vue / Angular):**
   * Значение устанавливается через `e.target.value = ...` с вызовом только события `input`. В React это часто не обновляет внутренний state компонента без эмуляции нативного сеттера (`HTMLInputElement.prototype`).
5. **Производительность при большом числе локаторов:**
   * При каждом клике в активном режиме выполняется обход всех XPath-выражений через `document.evaluate(...)`, что может приводить к микрофризам страницы при сотнях локаторов.
6. **Хрупкая валидация импорта JSON:**
   * Функция `validateImport` в `utils.js` проверяет строгий порядок и количество ключей (`Object.keys(v)[0] != 'desc'`), из-за чего валидный JSON с другим порядком ключей будет отклонён.
7. **Устаревший подход к вёрстке настроек:**
   * Использование `<iframe>` в `options.html` для переключения страниц вместо SPA/компонентов или Bootstrap Tabs.
8. **Неточности в документации:**
   * В `README.md` упоминается функционал вставки версии в YouTrack, который отсутствует в коде (видимо, остался от ранней идеи).

## 6. Рекомендации по улучшению (Roadmap)

### 🚀 6.1. Расширение функционала
* [ ] **Генерация кириллицы и реалистичных данных:**
  * Добавить шаблоны: `%cyr[N]` (русские буквы), `%fio` (генерация реалистичных ФИО по полу), `%oms` (полис ОМС), `%inn` (ИНН с контрольной суммой), `%passport` (паспорт РФ).
* [ ] **Гибкий генератор дат:**
  * Поддержка диапазонов и относительных дат: `%date(min, max)`, `%date(today)`, `%date(adult)`.
* [ ] **Режим «Заполнить всю форму» (Fill All):**
  * Добавить возможность заполнения всех найденных на странице полей по одному клику / горячей клавише, а не только поочерёдно.
* [ ] **Профили / Пресеты данных:**
  * Создание сценариев (например, «Взрослый пациент», «Ребёнок», «Иностранец», «Пенсионер»).

### 🛠 6.2. Технические и архитектурные улучшения
* [ ] **Поддержка любых доменов (Настраиваемые хосты):**
  * Использовать `host_permissions: ["<all_urls>"]` или `activeTab` с возможностью включения на любом открытом сайте.
* [ ] **Корректная работа с React/Vue:**
  * Использовать вызов нативного сеттера:
    ```javascript
    const nativeSetter = Object.getOwnPropertyDescriptor(window.HTMLInputElement.prototype, 'value').set;
    nativeSetter.call(element, value);
    element.dispatchEvent(new Event('input', { bubbles: true }));
    element.dispatchEvent(new Event('change', { bubbles: true }));
    ```
* [ ] **Безопасное обновление данных в Storage:**
  * В `background.js` сохранять существующие пользовательские локаторы при обновлении расширения, выполняя `merge`, а не `clear()`.
* [ ] **Надёжная валидация импорта:**
  * Проверять наличие свойств объекта по именам (`v.desc && v.xpath && v.value`), а не по индексам в `Object.keys`.
* [ ] **Отказ от `<iframe>` в настройках:**
  * Перевести `options.html` на стандартные Bootstrap вкладки (Tabs) для более удобного и бесшовного UX.
* [ ] **Покрытие тестами:**
  * Добавить модульные тесты для `randomStringUtils.js` (генерация СНИЛС, дат, шаблонов) с помощью Jest / Vitest.

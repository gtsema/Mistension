# Stage 02 — Fill All & Profiles

## Goal
Implement a one-click mass autofill capability and support named test profiles/scenarios.

## Scope
- "Fill Entire Form" action (triggerable via shortcut or popup button) to evaluate all locators at once and fill all matching inputs on the page.
- Profiles support: switch between profiles like "Standard Adult", "Child Patient", "Pensioner", "Foreign Citizen".
- Profile selection UI in options and popup.

## Acceptance Criteria
- User can trigger "Fill All", populating all present form inputs with a single action.
- Locators can be categorized or grouped by profile.

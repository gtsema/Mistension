# Development Stages

This directory contains stage definitions following the OpenCode Stage-Based Delivery workflow.

## Stages Roadmap
1. **Stage 00 — Foundation (Current Baseline):** Manifest V3 extension, click-to-fill autofill mode, SNILS/date generators, options UI, import/export.
2. **Stage 01 — Data Generation Expansion:** Support Cyrillic (%cyr), Russian FIO, OMS policy, INN, dynamic dates (%date(min, max)).
3. **Stage 02 — Form Autofill Modes & Profiles:** One-click "Fill entire form" feature, preset profiles (Adult, Child, Pensioner).
4. **Stage 03 — Modern UI & Storage Hardening:** Migration to non-destructive storage merge, Bootstrap tabs instead of iframe, automated test suite.

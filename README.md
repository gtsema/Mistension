<h1 align="center">Mistension</h1>

## Описание и назначение проекта
**Mistension** (сокращение от *МИС + Extension*) — это браузерное расширение для Google Chrome (Manifest V3), разработанное специально для QA-инженеров и тестировщиков медицинских информационных систем (МИС). 

Основная цель проекта — автоматизировать и ускорить процесс ручного ввода валидных тестовых данных при заполнении сложных медицинских форм (карточки пациентов, заказы, адреса, документы, контакты и др.).

## 🚀 Установка
Расширение работает в режиме разработчика (Developer Mode) в браузере Google Chrome:
1. Клонируйте или скачайте данный репозиторий.
2. Откройте в Chrome страницу `chrome://extensions/`.
3. В правом верхнем углу включите переключатель **Режим разработчика** (Developer mode).
4. В левом верхнем углу нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) и укажите папку `Mistension`.
5. Перейдите в `chrome://extensions/shortcuts` и настройте удобную комбинацию клавиш для действия **«Автозаполнение»** (по умолчанию `Ctrl+Shift+F` / `Cmd+Shift+F`).

## ⚡ Использование

### 1. Интерактивное автозаполнение
1. Откройте страницу тестируемой МИС (по умолчанию `https://*.medzoom.ru/*`).
2. Нажмите горячие клавиши `Ctrl+Shift+F` — курсор мыши изменится на **«волшебную палочку»**.
3. Кликните по любому полю ввода, для которого задан локатор — поле будет автоматически заполнено сгенерированными данными (с анимацией конфетти).
4. Нажмите `Ctrl+Shift+F` повторно для отключения режима.

### 2. Настройка локаторов
Откройте страницу настроек расширения (клик правой кнопкой мыши по иконке кота -> *Параметры*):
* **Добавление:** Нажмите кнопку *«+ Добавить локатор»*, укажите название поля, селектор (**XPath** или **CSS**), фильтрацию по URL страниц (опционально) и шаблон генерации.
* **Фильтрация по URL:** Поле *«Страницы (URL)»* позволяет ограничить срабатывание локатора конкретными адресами (статический URL или с маской `*`, например `/patients/create*`, `https://*.medzoom.ru/*`, через запятую). Если поле пустое — локатор активен на всех страницах.
* **Импорт / Экспорт:** Загрузка и выгрузка базы локаторов в формате JSON (`mistension_locators.json`).

### 3. Шаблоны генерации данных
Поле `value` локатора поддерживает специальные шаблоны:
* `%snils` — валидный СНИЛС с расчётом контрольной суммы.
* `%date` — дата рождения в формате `DD.MM.YYYY` с циклом переключения по кликам:
  * 1-й клик: несовершеннолетний (0–18 лет);
  * 2-й клик: ровно 18 лет;
  * 3-й клик: взрослый (18–100 лет);
  * далее по кругу (1 -> 2 -> 3 -> 1...).
* `%d[N]` — `N` случайных цифр (например, `%d4` для серии паспорта, `%d6` для номера).
* `%s[N]` — `N` латинских букв.
* `%m[N]` — `N` буквенно-цифровых символов.
* Обычный текст — вставляется без изменений (например, `г. Санкт-Петербург`).
